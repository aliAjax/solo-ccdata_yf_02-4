# 评审白板 · Review Board

在原协作白板基础上升级为**带角色与阶段门禁的评审空间**。纯前端实现，打开 `index.html` 即可使用（建议用静态服务器：`python3 -m http.server`）。

## 角色与权限

- **主持人**：创建评审并指定成员身份；可绘制、提交意见、管理成员（改身份/移除）、裁决冲突、推进与回退阶段。
- **编辑者**：绘制/拖动/编辑/删除元素、提交意见与图片证据、流转意见状态。
- **观察者**：只读，可浏览画板、意见、审计并导出 PNG。
- 归档阶段空间锁定，所有身份均为只读。

## 意见

每条意见包含 **内容、负责人、优先级（高/中/低）、状态**（待处理 → 核验中 → 通过/驳回，状态流转受限不能跳级）、**图片证据**（≤2MB 转存本地）、可关联画板元素。

## 阶段门禁

收集 → 讨论 → 决议 → 归档，仅主持人可推进，条件不足不能跳步：

- 收集→讨论：至少 1 条意见；
- 讨论→决议：没有「待处理」意见；
- 决议→归档：所有意见必须给出「通过/驳回」结论；
- 主持人可回退阶段；每次尝试与变更（含被门禁阻止）都写入审计。

## 冲突裁决

两人同时改动同一元素（基于同一旧版本分叉）时，系统**同时保留两个版本**：画板元素进入冲突态并锁定，顶部出现冲突提示，由主持人选择版本 A/B 或在合并框中合并后写入；裁决动作记入关键审计并同步所有标签。

## 同步与恢复

- `localStorage` 持久化评审，刷新/重开（入口页本机记录或邀请链接）恢复数据与身份；
- `BroadcastChannel` 多标签实时同步（元素、意见、阶段、成员、冲突、审计、在线状态），storage 事件兜底。

## 保留的白板能力

便签/文本/矩形/圆形/连线绘制、颜色、拖动、双击编辑、Delete 删除、撤销（⌘Z）、PNG 导出（真实 Canvas 渲染并下载），窄屏（≤720px）下创建→绘制→意见→推进的核心流程可用。

## 文件

- `index.html` / `styles.css` / `app.js`：应用。
- `.verify/`：Playwright 真实浏览器端到端测试（`run-tests.mjs`，53 项断言）与 jsdom DOM 级测试（`dom-tests.mjs`，57 项断言）。
